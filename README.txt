FAIRY // LOCAL MODEL LINK  ——  使用说明（分享版）
=================================================

这是一个纯本地运行的桌面小应用：界面在你自己电脑上，对话内容由你本机
LM Studio 里的模型生成，不会上传到任何地方。

【重要：本分享版不含任何训练音色】
出于声音版权考虑，包里没有内置 Fairy / YouKai 的 GPT-SoVITS 权重和参考音频，
也没有任何 wav / pth / ckpt 音频与模型文件。开箱用的是 Windows 系统音色。
想接自己的 GPT-SoVITS：设置里把「语音引擎」切到 GPT-SoVITS，
填上你自己的服务地址（如 http://127.0.0.1:9880/tts）和参考音频路径即可。


一、需要准备什么
--------------
1) **不用装 Node.js** —— 压缩包里自带了运行时（runtime\node.exe）。
   解压后请保持整个文件夹完整，不要只把几个文件拖出来。
2) 安装 LM Studio：https://lmstudio.ai/
   - 下载并加载一个中文模型；
   - 打开本地服务：左侧「Developer」（开发者）→ 右上角把服务打开（Started，默认 1234 端口），
     或者勾上「加载模型时自动启动服务」。
   注意：本应用不会替你拉起 LM Studio 的后台服务，需要 LM Studio 自己开着。
3) 需要 Edge 或 Chrome 之一（用于「无地址栏的全屏窗口」）。
   两个都没有也没关系，会退回默认浏览器，手动按 F11 全屏。


二、怎么运行
----------
双击 **Start-Fairy.bat**（英文名的那个）。

- 打开时会先播一段**开机动画**（Fairy 开机音效 + 自检日志逐字打印），
  点一下鼠标或按 Esc 可以随时跳过；从 Fairy 切到 YouKai 时还会再播一段
  YouKai 的开场动画。没有声音的话多半是系统没装中文语音包（见常见问题）。
- 界面会用 Edge / Chrome 的独立应用窗口打开：没有标签页、没有地址栏，
  启动就是全屏，按 **Esc** 退出全屏。
- 黑窗口里如果出现黄色的「体检提示」，说明 LM Studio 的本地服务没开，
  照提示去 LM Studio 里把服务打开即可（界面能开，但对话会失败）。
- 右上角可以设置模型、音色、人格等参数；左下角直接打字对话。


三、怎么停止
----------
关掉界面窗口**不会**停掉后台服务（它是无窗口运行的）。
要彻底停掉：双击 **Stop-Fairy.bat**。下次双击 Start-Fairy.bat 即可再打开。


四、两个智能体
------------
- Fairy：蓝白配色，自称Ⅲ型总序式集成泛用人工智能，嘴硬心软的毒舌管家。
- YouKai：红色配色，毒舌、讥诮、效率的另一台智能体。
顶栏「◉ Fairy / YouKai」按钮随时切换。两人能看到同一段对话上下文，
并且互相看不顺眼——会互相拆台，这是故意的。


五、常见问题
-----------
- **双击没反应 / 一闪而过**：确认是「解压整个文件夹」后再运行的；
  右键 Start-Fairy.bat → 以管理员身份运行 再试一次。
- **打开后连不上模型**：本应用会自动扫描 LM Studio 的端口和路径
  （兼容 0.4.x 新版，端口或地址变了也能自己找到），确认 LM Studio 界面开着、
  服务是 Started，并且**已经加载了一个模型**。
  设置里的「本地模型地址」默认 http://127.0.0.1:1234/v1，扫到别的地址会在状态栏说明。
- **端口被占用**：设置里换一个端口，或先双击 Stop-Fairy.bat。
  （本包初始端口是 5178，避免和其它已有的 Fairy 抢 5177）
- **没有声音**：设置里把语音引擎切成「系统离线音色」并选一个中文语音；
  Windows 没装中文语音包的话，可以切「在线音色（需联网）」。
- **还说打不开**：看 data\server.log 和 data\server.err.log，里面写着具体原因。
- 配置和日志都保存在本目录的 data\ 里，不会写到系统用户目录，
  也不会影响同一台机器上其它版本的 Fairy。


六、目录结构
-----------
Start-Fairy.bat        双击运行（入口）
Stop-Fairy.bat         停掉后台服务
start-fairy.ps1        启动脚本（拉起服务 + 开全屏窗口）
open-fairy-window.ps1  用无地址栏的全屏应用窗口打开界面
stop-fairy.ps1         停止脚本
runtime\node.exe       自带的 Node.js 运行时（免安装）
server.js / lib / public   应用本体
assets\*-persona.txt   两个智能体的人格设定（可以自己改）
data\                  配置与日志（自动生成）
README.txt             本文件
